DIAGRAM 9: RESPONSIVE BEHAVIOR TREE
================================================================================

Window Resize Event
│
├─→ Viewport Width < Previous
│   └─→ Viewport shrinks (maintains aspect ratio)
│       └─→ Panel width unchanged (remains ~300px)
│           └─→ Horizontal scrollbar may appear
│
├─→ Viewport Height < Previous
│   └─→ Viewport shrinks vertically
│       └─→ Toolbar/menu/status maintain size
│           └─→ Splitters may reach minimum (400px)
│
├─→ Window Width < 1280px (Minimum)
│   ├─→ Horizontal overflow likely
│   ├─→ Right panel may overlap viewport
│   └─→ NOT RECOMMENDED (minimum spec is 1280×720)
│
└─→ Window Height < 720px (Minimum)
    ├─→ Vertical overflow likely
    ├─→ Debug console may be hidden
    └─→ NOT RECOMMENDED
