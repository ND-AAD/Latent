# Keyboard Shortcuts Reference
## Ceramic Mold Analyzer

**Quick access:** Press **F1** anytime to see this help

---

## Tab Navigation

| Shortcut | Action |
|----------|--------|
| **F1** | Switch to FILE tab |
| **F2** | Switch to ANALYZE tab |
| **F3** | Switch to EDIT tab |
| **F4** | Switch to VALIDATE tab |
| **F5** | Switch to FABRICATE tab |
| **F6** | Switch to VIEW tab |

---

## Edit Modes

| Shortcut | Action |
|----------|--------|
| **S** | Switch to Solid mode |
| **P** | Switch to Panel mode |
| **E** | Switch to Edge mode |
| **V** | Switch to Vertex mode |

---

## Selection

| Shortcut | Action |
|----------|--------|
| **Ctrl+A** | Select all elements in current mode |
| **Ctrl+I** | Invert current selection |
| **Escape** | Clear selection |
| **Ctrl+>** | Grow selection to neighbors |
| **Ctrl+<** | Shrink selection |

---

## Edit Operations

| Shortcut | Action |
|----------|--------|
| **Ctrl+Z** | Undo last action |
| **Ctrl+Shift+Z** | Redo last undone action |

---

## File Operations

| Shortcut | Action |

| **Ctrl+O** | Connect to Rhino |
| **Ctrl+R** | Load geometry from Rhino |

## Navigation Tips

1. **Tab key** moves through all interactive elements in logical order
2. **Shift+Tab** moves backwards through elements
3. **Enter** activates the focused button
4. **Space** toggles checkboxes and activates buttons
5. **Arrow keys** navigate between radio buttons
6. **Escape** cancels dialogs and clears selections
7. **Up/Down arrows** navigate command history in console input

---

## Accessibility Features

- All functions accessible via keyboard
- Clear focus indicators on all interactive elements
- Screen reader compatible
- High contrast mode available
- Logical tab order throughout application
- Tooltips show keyboard shortcuts

---

## Getting Help

- Press **F1** to show this shortcuts dialog
- Hover over any button to see its tooltip with shortcut
- Check status messages in bottom panel
- Use debug console (Ctrl+`) for detailed logging
